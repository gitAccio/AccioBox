Contenuti
Una cartella per materia: `content/formulario/<area>/<materia>/` con `_materia.yaml` e `formule.yaml` (lista di schede).
Campi scheda: id, nome, latex, expr (es. `F = m*a`), stato (verificato|da_verificare|bozza), fonte, ipotesi, variabili {simbolo: "Descrizione [unità]"}.
Per aggiungere una materia basta creare la cartella: nessuna modifica al codice.
