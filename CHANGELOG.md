# Changelog
0.1.0 - shell 5 tab, Risolutore + studio di funzione, calcolatrice, convertitore + analizzatore unità, formulario YAML calcolabile, costanti, backup.

0.2.0 - Tastiere a pulsanti (calcolatrice, risolutore, convertitore a menu), Formulario per area/materia, validatore contenuti (`npm run validate`, eseguito in test e build), error boundary, ricerca universale in Home, dashboard configurabile (Profilo), appunti per formula, Database materiali (valori tipici da_verificare), scheletro di tutte le materie della specifica, 69 formule.

0.3.0 - PWA: manifest, icone, service worker con precache (vite-plugin-pwa), aggiornamento automatico, stato offline e pulsante Installa in Profilo. Test: `npm run build && npm run preview` (il service worker non gira in `npm run dev`).

0.4.0 - Rinominato AccioBox. Risolutore: tastiera di sistema, lettere libere (equazioni lineari/quadratiche simboliche, "risolvi per", definizioni "a=2;", studio di f(t), y=...), grafico con assi/griglia/etichette, zoom sul cursore, pizzico, pan, "Adatta vista". Calcolatrice: inserimento nel punto del cursore; dopo "=" un operatore riusa il risultato, una cifra riparte da zero. Convertitore: cursore ovunque + tastiera di sistema opzionale. Nuovo design (header, icone, tasti per tipo). Test di avvio dell'intera UI (jsdom).

0.5.0 - Tema Industrial Terminal nero/verde (da file utente) + correzioni di layout: tastiera a colonne minmax(0,1fr) e altezza fissa, barra in basso con altezza fissa e spazio riservato, righe senza sovrapposizioni, segmenti scorrevoli. Nuovo: Grafici (più funzioni, parametriche, intersezioni, legenda), Calcolatori (Mohr, trave appoggiata q/F, mensola, 3 sezioni, Reynolds/Darcy, gas ideale) con passaggi e avvisi di validità, Statistica (descrittiva, regressione polinomiale con R²). Logica in src/calc.ts con test. Zip include .github/workflows/deploy.yml e .gitignore.

0.6.0 - Formulario esteso a tutte le materie dello scheletro: 466 schede (397 nuove). Le schede di sola teoria (derivate, integrali, Laplace, Fourier, teoremi vettoriali, complessità…) non hanno calcolatore. Tutte le schede sono `da_verificare` finché non confrontate con una fonte (le 69 precedenti erano "verificato" senza una verifica reale). Validatore: `expr`/`variabili` facoltativi, controllo di coerenza simboli↔variabili su ogni scheda.

0.7.0 - Contenuti ristretti al piano di studi di Ingegneria Meccanica UniBAS (Manifesto degli Studi 2026/27: laurea triennale L-9 e magistrale LM-33): 34 insegnamenti con i nomi ufficiali, ordinati per anno (campo `ordine` in `_materia.yaml`). Eliminati i corsi non presenti nel piano. Fisica II (Elettricità e magnetismo) ampliata a 86 schede (elettrostatica, capacità, corrente, magnetostatica, induzione, circuiti, Maxwell, onde, polarizzazione/diffrazione). Fisica I completata con lavoro-energia, onde, entropia, teoria cinetica, van der Waals.
